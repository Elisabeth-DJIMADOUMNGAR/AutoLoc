# AutoLoc

Plateforme de gestion de location de véhicules multi-agences.

## Objectifs
- Gérer les véhicules, agences, réservations et contrats de location
- Offrir une API REST (Spring Boot) testée avec Postman

## Acteurs
- **Client** : consulte les véhicules, réserve, suit ses locations
- **Agent d'agence** : enregistre les locations et les retours
- **Responsable d'agence** : supervise son agence
- **Administrateur** : gère les agences, les utilisateurs et les paramètres

## Stack technique
Java 17, Spring Boot, Maven, MySQL, IntelliJ IDEA, Postman, Git
